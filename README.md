# Rozogorod на React

Локальная версия витрины доставки цветов в Юрге. За основу взяты [публичный сайт Rozogorod](https://rozogorod.ru/yurga) и скриншоты его настольной версии. В проект вошли 144 товарные позиции с фотографиями, в том числе 61 позиция с главной страницы. Цены и состав каталога зафиксированы на 18 ноября 2026 года.

## Запуск в VS Code

1. Распакуй архив и открой папку `rozogorod-react` через «Файл → Открыть папку». В корне должны быть видны `package.json` и `src`.
2. Используй Node.js 22.12+ или 24 LTS. Проект проверен на Node.js 24.
3. Открой терминал в этой папке и выполни команды по очереди.

```bash
npm ci
npm run dev
```

Открой адрес, который Vite выведет в терминале, обычно http://localhost:5173/yurga. При изменении JSX и CSS браузер обновит страницу. В Windows PowerShell при ошибке запуска `npm.ps1` используй `npm.cmd ci` и `npm.cmd run dev`.

Для сборки выполни `npm run build`. Команда `npm run preview` откроет собранные файлы из `dist` через локальный сервер. Для публикации на обычном веб-сервере нужно отдавать `index.html` при прямом открытии маршрутов вида `/yurga/item/1935`.

## Структура проекта

| Файл или папка | Что находится внутри |
| --- | --- |
| `index.html` | HTML с элементом `root`. В него React монтирует приложение. Здесь же начальный заголовок вкладки и иконка. |
| `src/main.jsx` | Точка входа, подключение стилей, провайдера корзины и таблица маршрутов React Router. |
| `src/components/Layout.jsx` | Общие блоки всех страниц. Компонент `Header` выводит контакты и меню, `Toolbar` отвечает за поиск, каталог и счётчик корзины. Ниже располагаются подборки и футер. На месте `Outlet` появляется текущая страница. |
| `src/components/Products.jsx` | Повторно используемые компоненты `ProductCard`, `Price`, `AddButton` и `ProductGrid`. Здесь расположены цены, значок акции, кнопка добавления и подгрузка карточек. |
| `src/pages/Catalog.jsx` | Главная `Home`, баннер, круговые иконки, результаты поиска и страницы категорий. Компонент `Catalog` обрабатывает фильтры по цене и популярности, а также сортировку. |
| `src/pages/Product.jsx` | Подробная карточка товара. Фото можно открыть крупнее. Здесь выводятся цена, описание, кнопка покупки, дополнения и похожие товары. |
| `src/pages/Cart.jsx` | Состав корзины, изменение количества, удаление, сумма и переход к оформлению. |
| `src/pages/Order.jsx` | Заказ из корзины и заявка по фото. Формы поддерживают самовывоз, доставку, выбор даты и времени. `PhotoPicker` принимает до четырёх JPG или PNG, показывает миниатюры и позволяет удалить файл. |
| `src/pages/Info.jsx` | Страницы доставки, оплаты, контактов и локальные отзывы. |
| `src/store/Cart.jsx` | Общее состояние корзины, проверка сохранённых значений, расчёт количества и суммы. Компоненты получают их через хук `useCart()`. |
| `src/data/products.json` | Список товаров. У каждой записи свой ID, название, категория, цена, имя изображения и признак показа на главной. |
| `src/data/shop.js` | Список категорий с иконками, ссылки меню, контакты, правила подбора и функции построения адресов. |
| `src/styles.css` | Оформление витрины. Здесь задаются цвет `--pink`, ширина `.wrap`, размеры фото, число колонок и мобильные правила. |
| `src/vendor/bootstrap/` | Локальная сетка Bootstrap 5.3.3 и её лицензия. Используется в формах заказа через `row`, `row-cols-1`, `row-cols-md-2` и `g-3`. |
| `public/images/site/` | Логотип, рекламный баннер, иконки категорий и графика шапки и футера. |
| `public/images/products/` | Фотографии товаров. Пути начинаются с `/images/`, потому что Vite раздаёт содержимое `public` от корня сайта. |
| `package.json`, `package-lock.json` | Команды разработки и зафиксированные версии зависимостей. |

## Как работают переходы

| Адрес | Что он открывает |
| --- | --- |
| `/yurga` | Главная с категориями и популярными товарами |
| `/yurga/catalog/1886` | Раздел «Букеты с розами» |
| `/yurga/catalog/actions` | Товары со старой и новой ценой |
| `/yurga/catalog/all` | Весь локальный каталог |
| `/yurga/search?q=розы` | Поиск по названиям и категориям |
| `/yurga/item/1935` | Карточка букета «Комплимент» |
| `/yurga/cart`, `/yurga/checkout` | Корзина и оформление заказа |
| `/yurga/bouquet-photo` | Форма заказа по образцу фотографии |
| `/yurga/page/dostavka`, `/yurga/page/oplata`, `/yurga/page/contacts` | Информация магазина |
| `/yurga/reviews` | Просмотр и добавление локальных отзывов |

Например, `Link` на карточке ведёт на `/yurga/item/1935`. Маршрутизатор сопоставляет этот адрес с `item/:id`. В `Product.jsx` хук `useParams()` возвращает ID, а `productById[id]` находит запись. Поэтому для каждого букета достаточно одной записи в JSON и одного компонента для всех товаров.

## Как работает каталог

На главную попадают товары с `popular: true` в порядке их следования в JSON. `ProductGrid` сначала выводит восемь карточек. В конце списка находится «Показать ещё». При нажатии на неё или появлении блока в зоне видимости `IntersectionObserver` увеличивает количество показанных карточек. Это воспроизводит замеченное на живой странице поведение. Новые строки берутся из уже загруженного локального массива.

Для ручного перелистывания измени `ProductGrid` в `Products.jsx`. Чтобы оставить только «Показать ещё», достаточно убрать эффект с `IntersectionObserver`. Для нумерованных страниц храни номер в параметре URL `page` и показывай срез массива для этой страницы. На страницах категорий примеры работы с параметрами URL уже есть в `Catalog.jsx`.

## Как работают корзина и заказ

`AddButton` вызывает `change(product.id, 1)`. Провайдер обновляет количество, пересчитывает итог и записывает корзину в `localStorage` под ключом `rozogorod.cart.v1`. Страница корзины читает то же состояние. При перезагрузке браузера провайдер восстанавливает выбранные позиции.

Форма в `Order.jsx` проверяет обязательные поля, создаёт локальное подтверждение и очищает корзину после обычного заказа. Заявка по фото оформляется отдельно. Контактные данные и фотографии остаются в памяти страницы. Отзывы сохраняются в `localStorage` отдельно, под ключом `rozogorod.reviews.v1`.

## Как добавить товар

1. Сохрани фото в `public/images/products/`, например под именем `3001.jpg`.
2. Добавь в массив `src/data/products.json` объект с уникальным строковым ID. Для примера ниже используется раздел роз с ID `1886`.

```json
{
  "id": "3001",
  "name": "Букет из девяти роз",
  "category": "1886",
  "price": 3200,
  "oldPrice": 3500,
  "image": "/images/products/3001.jpg",
  "popular": true,
  "description": "Девять роз в светлой упаковке."
}
```

Карточка появится в категории, поиске, акциях и на главной. Удали поле `oldPrice`, если у товара обычная цена. Для отдельного фото высокого разрешения добавь `largeImage`. Категорию можно добавить в массив `categories` в `shop.js` и указать её строковый ID в товарах.

## Что подключать при развитии

Сейчас это самостоятельная витрина для одного города. Источник товаров — JSON, фотографии лежат в проекте. Магазинные остатки, сервер заказов, авторизация и платёжный шлюз потребуют интеграции с реальным магазином. Чтобы перейти на API, начни с загрузки каталога в слое данных и отправки проверенного заказа из обработчика `submit` в `Order.jsx`. Для реальных продаж цену и наличие должен заново проверять сервер.

Графика витрины и фотографии взяты со страниц Rozogorod. Лицензия в `src/vendor/bootstrap/LICENSE` относится к Bootstrap. В копии справочная информация сокращена, подборки по поводу и получателю составлены локально, отзывы начинаются с пустого списка. Оригинальная страница доставки и баннер указывают разные суммы бесплатной доставки. Перед запуском продаж магазин должен выбрать и подтвердить единое условие.
